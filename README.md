# 微博长文收集记录整理器 v0.5.2

通过模拟 Edge 浏览器访问微博 PC 端,自动收集指定博主在指定时间段内的**原创长文微博**,并导出为 Markdown/Word 文件。页面类名(微博前端会不定期修改)由程序**自动识别**,无需手动维护。支持本地热度/字数筛选与可选 AI 智能分类。

> ## 友情提示
>
> 本项目由 DeepSeek 写成,供本人和好友使用,功能并不完善,可能不适用他人的电脑。

## 功能特性

- **自动识别页面类名**:微博前端类名(CSS Modules 哈希)变化时,程序自动探测新类名并保存,无需改代码;极端情况支持手动输入
- **GUI 图形界面**(V0.3.0 起只发布 GUI 版本)
- 按博主 + 时间范围批量导出,输出内容:URL、发布时间、话题、正文、转发/评论/点赞数
- 自动跳过转发微博,只收集原创长文
- 重跑同一时间段时自动覆盖旧文件
- 博主在选定时间段无微博(如禁言)时给出友好提示
- **按月保存**:无论爬取多长或多短的时间范围,均按 YYYY-MM 月份文件夹归类保存
- **可自定义爬取间隔**:避免被微博风控
- **可选下载图片/视频**:将微博中的图片、视频下载到本地
- **导出格式可选**:Markdown 或 Word(docx)
- **日期选择器**:GUI 中年/月/日选择,年份范围 10 年前~明年(可手动输入),自动处理每月天数与闰年
- **本地筛选功能**:对已爬取数据按**转评赞之和**或**正文字数**排序筛选,输出前 N 篇到"筛选"文件夹(带排名序号)
- **跳过已爬取的文章**:按微博ID去重,重跑时不再重复抓取已存在的文章
- **博主记录文件**:DataPC/博主记录.txt,博主昵称下拉选择自动填充ID,支持手动编辑
- **爬取前博主校验(V0.5.1)**:爬取前自动核对微博ID是否存在、昵称是否与ID匹配;不存在或不匹配会在**开始前**明确提示(不再误报"该时间段无微博"),校验不通过的博主不会写入记录文件;记录文件按页面真实昵称追加
- **最低字数过滤**:正文低于指定字数的文章不导出(高级设置,列表页同时粗过滤,节省时间)
- **AI 智能筛选(可选,V0.4.0)**:接入任意 OpenAI 兼容大模型 API(DeepSeek/通义/Kimi 等,默认模型 deepseek-v4-flash):
  - 爬取时**实时判断**文章"高质量可信度",低于阈值不导出;通过的文章标注可信度
  - 对已爬取文章**事后分类**(高质量/广告/可疑/其他低质量),复制到 `AI分类/AI_博主_类别` 文件夹(默认保留原文件)
  - 可选 **AI 总结**:生成标题写入 AI总结.txt,或重命名为 `日期_AI标题`(按名称排序即按日期排序)
  - 筛选页可对 AI 分类结果再次按热度/字数筛选(数据源下拉)
  - 实时AI分类结果**默认连带复制图片/视频**到 AI分类 目录(V0.5.1;取消勾选则副本引用原微博网络链接,不占用本地空间,需联网查看)
- **微博状态记录(V0.5.2)**:每个博主一个 `微博状态.json`,记录每篇的发布时间/AI判定分数与时间/是否导出/转评赞及检查时间/媒体有无;重跑时**默认复用上次AI判定**(不再反复调用大模型,结果稳定、省tokens),可勾选"重跑时重新AI判断"强制重判
- **更新转评赞(V0.5.2)**:选择月份范围(或全部),逐篇抓详情**只刷新转发/评论/点赞数字**,正文与AI分类文件夹不动;建议月末/季末/年末各跑一次;支持中途停止(已完成部分保留)
- **实时+事后分类防重复(V0.5.2)**:已通过"AI总结并重命名"复制到AI分类的文章,事后分类时默认跳过(可勾选"包含已实时分类的文章"重新分类)
- **其他改进(V0.5.2)**:停止按钮改为优雅停止(当前条目处理完即停);同一时间只允许一个程序实例;无头模式与"完成后保留浏览器"互斥;确认无图/无视频时自动写标记,重跑不再反复抓详情
- **打开文件夹按钮**:爬取/筛选页"打开月份文件夹"一键直达所选月份的源文件目录;日志区"打开数据目录"直达 DataPC 根
- **筛选结果按博主分目录**:输出到 `筛选\<博主名>_<ID>\`,多位博主不混杂;V0.5.1 起文件夹名包含**日期范围(省略年份前两位)+ 数据源 + 勾选指标**(如 `26-08-01~26-08-31_热度TOP10_AI_高质量_转发`),不同数据源/指标组合互不混杂

## 获取方式(二选一)

### 方式一:直接下载 exe(推荐,无需安装 Python)

到右侧 **Releases** 页面下载最新版的 `weibo-collector-GUI.exe`(图形界面),**双击即可运行**,无需安装 Python,理论上只需要电脑里有 edge 浏览器。

> 注意:exe 版运行时会在**自身所在文件夹**下自动创建 `EdgeUserData`(登录状态)、`DataPC`(爬取结果)和 `筛选`(筛选结果),请放在有写权限的文件夹中。

### 方式二:下载源码运行(适合想查看/修改代码)

源码运行需要:
- Windows 10/11
- **Microsoft Edge 浏览器**(Win10/11 自带,无需安装)
- Python 3.10+([下载地址](https://www.python.org/downloads/),安装时勾选 *Add python.exe to PATH*)

> 浏览器驱动(msedgedriver)由程序通过 Selenium Manager **自动下载**与 Edge 版本匹配的驱动,无需手动安装。

```bat
:: 1. 首次使用:双击执行一键安装(创建虚拟环境并安装依赖)
安装.bat

:: 2. 启动图形界面
启动GUI.bat

:: 3. 或在命令行使用
命令行爬取.bat
```

也可以直接用命令行指定参数运行:

```bat
venv\Scripts\python.exe weibo_crawler_cli.py --name 卢诗翰 --uid 3276099007 --start 2026-04-01 --end 2026-04-30
```

参数说明:

| 参数 | 说明 |
|---|---|
| `--name` | 博主昵称 |
| `--uid` | 博主微博ID(主页 URL 中 `/u/` 后面的数字) |
| `--start` / `--end` | 起止日期,格式 `YYYY-MM-DD` |
| `--headless` | 无头模式(不显示浏览器窗口) |
| `--no-export` | 只收集微博ID,不导出 Markdown |
| `--keep-browser` | 完成后保留浏览器窗口 |
| `--min-interval` / `--max-interval` | 每条微博之间随机等待秒数范围,默认 3~8(勿设置过短,避免风控) |
| `--download-images` / `--download-videos` | 同时下载微博中的图片/视频到本地 |
| `--format md\|docx` | 导出格式,默认 md |
| `--card-class` 等 | 手动指定类名(自动识别失败时使用) |

不传参数直接运行 `weibo_crawler_cli.py` 会进入交互模式,按提示输入即可。

## 输出目录说明

结果按**月份文件夹**保存,便于长期积累:

```
DataPC\<博主名>_<ID>\                    ← 根目录
└─ 2024年\                               ← 按年份分文件夹
   ├─ <博主>_<ID>_2024-10-01_2024-10-31.txt  ← 微博ID列表(在年份目录)
   └─ 10月\                              ← 按月份分文件夹
      ├─ <博主>_24-10-10_xxx.md / .docx  ← 每条微博
      └─ images\                         ← 下载的图片(可选)
```

> 提示:无论选择多长(如数月)或多短(如两天)的时间范围,文章都会按**发布月份**归入对应的"年份\月份"文件夹(如 `2024年\10月\`),微博ID文件放入年份文件夹。建议先按 1 个月爬取试验,避免触发微博风控。

## 首次使用注意事项

1. **需要登录微博**:首次运行会弹出 Edge 浏览器窗口,请**扫码登录微博一次**。登录状态保存在本地(`EdgeUserData` 目录),后续运行免登录。
2. **输出目录**:结果保存在 `DataPC\<博主名>_<ID>\` 下,按 `年份\月份\` 归类:
   - `*.txt` — 微博 ID 列表(逗号分隔),位于年份文件夹
   - `*\<月份>\<日期>_<微博ID>.md` — 每条微博的 Markdown 文件
3. **只能爬取"原创长文"微博**:与个人使用需求一致,转发微博与短微博会被跳过。

## 常见问题 (FAQ)

**Q: 提示"博主可能在此时间段内没有发表微博"**
A: 博主在选定时间段内没有符合条件(原创长文)的微博,或处于禁言/停更状态。请确认时间范围。

**Q: 提示"无法确定微博卡片类名"并让我手动输入**
A: 微博前端改版导致类名结构变化,自动识别失败。请按提示在浏览器中按 `F12` 打开开发者工具,选中一条微博卡片,查看其 `class` 属性(形如 `_body_xxxx_63`),输入即可。程序会自动记住该值,下次无需再输入。

**Q: 浏览器驱动下载失败**
A: 程序通过 Selenium Manager 自动下载驱动。若网络受限,请确保能访问 `https://msedgedriver.microsoft.com/`。

**Q: 杀毒软件提示**
A: 程序为开源脚本,不会包含任何恶意代码;如杀软误报,请添加信任。
